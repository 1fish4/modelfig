# 风格与配色

本库的视觉由三个**正交**维度决定：

```
最终观感 = 风格（线条/字号/网格/边框） × 配色（用什么颜色） × 底色（白 / 米）
```

因此只需维护 `4 套风格 + 7 套配色 + 2 种底色`，就能组合出 **56 种观感**，
而不是把 56 种组合各写一遍。

---

## 一、风格（决定"长什么样"）

| 风格 | 线宽 | 字号 | 网格 | 图幅 | 导出 | 适用场景 |
|------|------|------|------|------|------|----------|
| `journal` | 1.5 pt | 8 pt | 无 | 89 mm | 600 dpi | 论文投稿、学位论文 |
| `soft` | 1.8 pt | 9 pt | 浅灰点线 | 140 mm | 400 dpi | 组会汇报、论文插图 |
| `slide` | 2.8 pt | 15 pt | 浅灰实线 | 230 mm | 200 dpi | 答辩 PPT、课堂展示 |
| `poster` | 3.6 pt | 19 pt | 无 | 280 mm | 300 dpi | 学术海报、远距离展示 |

### 共有的视觉约定

这六条是本库所有风格的共同基础，也是让图显得"专业"的关键：

1. **去边框（despine）** —— 只保留左、下两条轴线，不用四边封闭的方框
2. **轴细线粗** —— 坐标轴 0.6 pt，数据线 1.5~3.6 pt，约 1:3 的反差让数据"跳出来"
3. **字号偏小** —— `journal` / `soft` 用 8~9 pt，让图显密实而非松散
4. **网格若有若无** —— `soft` 用浅灰点线、透明度 0.75；`journal` 与 `poster` 完全不开
5. **标记描白边** —— 重叠的数据点更清爽
6. **紧凑布局** —— 启用 `constrained_layout`，元素自动对齐

### 风格说明

**journal —— 严谨期刊**
按 Nature / Science 的图幅规范设计：89 mm 单栏宽、8 pt 正文、0.6 pt 轴线、600 dpi。
不开网格，因为期刊图追求信息密度而非装饰。

**soft —— 柔和学术**
本库默认风格。在 `journal` 的基础上放大到 140 mm 以便屏读与打印兼顾，
加上一层极浅的点线网格辅助读数——网格刻意做得"若有若无"，避免抢走数据的注意力。

**slide —— 演示汇报**
字体放大到 15 pt、线宽 2.8 pt，保证投影后仍清晰；图幅 230 mm 接近 16:10，
直接贴进 PPT 不留白边。网格改用浅色实线，在低对比度的投影仪上比点线更稳定。

**poster —— 海报展示**
字号 19 pt、线宽 3.6 pt，为两三米外观看设计；去掉网格以保持远观的干净。

## 二、配色（决定"用什么颜色"）

色值全部取自科研绘图素材，逐像素采样并核对过印刷 HEX 标注。

配色分两类：**类别色（categorical）** 用于分组对比，**渐变色（continuous）** 用于有序数据。

> **排序原则**：类别色的颜色顺序按「相邻色差异最大」排列，而非按色相排列。
> 第 1、2 色通常是互补对，浅色系一律后置——浅色作线条几乎看不见，只适合填充。

### 暖橙冷蓝 `warm_cool`（渐变色，9 色）

渐变顺序（**不要打乱**）：

```
#D73221 深砖红 → #E35235 珊瑚红 → #E48070 暖粉橙 → #FCB777 浅杏橙
→ #FDE699 浅黄 → #FEF4AE 米黄 → #4573B4 中蓝 → #6491C1 浅蓝 → #D2EDF2 冰蓝
```

**本库唯一的暖冷渐变**，专为热力图与色阶映射设计。
`categorical("warm_cool")` 会返回一个按对比度重排的版本，供分组场景使用。

### 地学 `geo`（渐变色，10 色）

渐变顺序（**不要打乱**）：

```
#F07D7D 珊瑚粉 → #F4B37A 杏橙 → #F6D37A 沙黄 → #FFF186 淡黄 → #CFE7A4 黄绿
→ #9CC88A 鼠尾草绿 → #66A870 苔绿 → #4CB8B0 青绿 → #6FAFE6 天空蓝 → #2F4B88 深海蓝
```

冷暖跨度大，适合分区填色、地图配色与分箱色阶。

> **素材勘误**：原素材中「深青绿」印刷标注为 `#4596B8`，
> 但其 RGB 标注为 (69, 150, 136)，对应 `#459688`。标签自身不自洽，本库以 RGB 为准。

## 三、底色（可选）

| 名称 | 色值 | 说明 |
|------|------|------|
| `white` | `#FFFFFF` | 默认。通用，适合绝大多数场合 |
| `cream` | `#FAF7F1` | 米色底，观感更温和，适合报告与展示 |

```python
mf.set_style("soft", palette="misty_blue", background="cream")
```

> 投稿时请使用 `white`——多数期刊要求纯白底。

## 四、组合使用

```python
import modelfig as mf

# 查看全部可选
mf.style_names()                              # 风格名
mf.palette_names()                            # 配色名
mf.style_info()                               # 风格的中文标签、场景、视觉特征
mf.list_palettes()                            # 配色清单（标签、类型、色数、用途）
mf.describe_palette("soft_academic")          # 单套配色的完整色值

# 组合
mf.set_style("soft", palette="soft_academic")
mf.set_style("journal", palette="warm_cool")
mf.set_style("slide", palette="soft_multi", background="cream")
```

## 五、自定义

### 自定义风格

```python
mf.register_style("myschool", {
    "font.size": 12,
    "lines.linewidth": 1.8,
    "axes.grid": True,
    "grid.linestyle": ":",
})
mf.set_style("myschool", palette="soft_academic")
```

### 自定义配色

```python
# 简洁写法
mf.register_palette("myschool", ["#005BAC", "#E60012", "#009944"])

# 带中文标签的完整写法
mf.register_palette(
    "myschool",
    {"校蓝": "#005BAC", "校红": "#E60012"},
    label="校色",
    kind="categorical",
    usage="学校报告",
)
mf.set_style("soft", palette="myschool")
```

完整可用参数见 [matplotlib rcParams 文档](https://matplotlib.org/stable/users/explain/customizing.html)。
